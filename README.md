# 电商客服 Agent

基于 ReAct 的客服 Agent：模型自主决定工具调用、轮数与停止。RAG 以「检索即工具」接入，支持 TF-IDF / Embedding(bge-small-zh, ONNX) / Hybrid(RRF) 一键切换。

- 4 个受限工具：检索知识库 / 查询订单 / 创建工单 / 转人工
- 中文检索 + 阈值校准 + 抗误召回；多轮对话含上下文继承与安全历史裁剪
- 评估：30 条单轮、7 组多轮、50 条改写、1 万条干扰项规模实验
- 实测：单轮事实 97.7% / 幻觉 0%；多轮全轮通过 95.2%（裸模型 baseline 0%）；改写检索 R@3 在 1 万条库上 Embedding 80% vs TF-IDF 42%

> 数据均为本地模拟，仅用于演示 Agent 能力。
